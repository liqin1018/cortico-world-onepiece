# 海贼王大冒险 · 剧情模式设计稿（v0.3–v0.5）

> 目标：把现在「每天点一次出海、看一个数字」的循环，换成「她在一部 119 章的连载里往前爬」。
> 状态：v0.3 已实现（剧情线 + 等级 + 自动冒险）。第 6–8 节（船员 / 船 / 收藏）留给 v0.4 与 v0.5。

---

## 1. 为什么现在单调

不是内容少，是三件事都不成立：

- **没有位置感**。5 种航线语义完全等价，跑第 1 趟和第 40 趟的唯一区别是数字变大。玩家不知道「第几章」，也不知道「还差多远」。
- **没有积累**。赏金涨了，但她的船、她的船员、她会的东西都没变。所有成长都写在同一个数字上。
- **必须手动**。它是个「每日签到」，不是「她自己过日子」。桌宠的价值在「你没管她，她也在动」。

对应三处改：**章节进度 / 三条成长轴 / 自动冒险**。

## 2. 核心结构：一条主线 + 四条支撑

主线是**篇章**（剧情进度）。四条支撑各自解决一种「没有积累」：队伍、船、收藏、等级。缺任何一条都会退回到「数字变大」。
自动冒险不是第五个系统，它是把这套东西跑起来的方式——她不需要你在场。

**章节不是关卡，是航次**。每次出海推进一章（或被 BOSS 卡住）。所以现有「出海」这个动作不用重写，只是每次的结果从「赏金 +X」变成「你在第 11 篇第 3 章」。

四种节点，节奏才不会平：

- **航行**（约 55%）：纯推进，给材料和经验，失败只是慢一点
- **遭遇**（约 25%）：一场战斗，可能损船、掉道具
- **交涉**（约 12%）：三选一（硬闯 / 谈判 / 绕路），选项影响掉落与是否招到人
- **名场面**（约 8%）：固定结果 + 高奖励 + 稀有掉落，每篇最多一个。顶上战争、烧旗、五档都在这里

**锁定与跳过**：BOSS 章节必须满足等级与战力门槛才能打，但允许「绕过去先刷自由航海」；配置里可以开「允许跳章」，跳过只记进度不留奖励。

## 4. 结算：一条公式，五种结果

```
战力 P = 10 + 2.2×Lv + Σ船员战力 + 装备 + 船 + 果实 + 霸气
难度 D = 章节基准(10~900) × 部系数(东海 1.0 / 伟航 2.4 / 新世界 7.2)
r = P / D
```

| r | 结果 | 后果 |
|---|------|------|
| ≥1.6 | 碾压 | 全额奖励，10% 概率额外掉落 |
| 1.15–1.6 | 胜 | 全额奖励 |
| 0.95–1.15 | 惨胜 | 奖励 −20%，船体 −15 |
| 0.70–0.95 | 败走 | 奖励减半，船体 −30，进度保留（这是关键：**不重来**） |
| <0.70 | 被俘 | 掉 15% 财宝，押送 30 分钟，进度保留 |

**BOSS 打三回合**：每回合单独掷，累计伤害够了算赢；两回合内可以「撤退」，保进度、冷却 30 分钟。这样 BOSS 有紧张感，但不会变成劝退墙。

## 5. 船员：不是数值卡，是「谁能上船」

- 上限 10 人（配置 4–10），招募来自剧情节点 + 悬赏招募（花贝利）
- 每人一个**定位**，定位决定航海能开什么选项：航海士（走无风带）、医生（减伤）、厨师（恢复快）、船匠（修船便宜）、考古（读历史正文）、音乐家（士气）
- **疲劳**：连续出海 3 次进「累」状态，战力 ×0.8，逼你轮换
- **支线派遣**：不随行的船员可以派出去，2–6 小时带材料回来（离线收益，也是她「有事在做」的来源）
- **好感**：一起打 BOSS 涨，好感 3 级解锁一句专属台词（只在回执里出现一次，控制 token）

## 6. 船：进度门槛 + 一次告别

- 四级：小帆船 → 梅丽号 → 千里阳光号 → 巨人战船
- 六个部件：船体 / 帆 / 舵 / 炮 / 厨房 / 图书馆（图书馆解锁图鉴加成）
- 材料：木材、铁、珊瑚、宝树亚当、海楼石。来自航海、拆解、支线
- 船是**地理门槛**：小帆船进不了新世界（用海流解释），所以换船是硬需求，不是数值优化
- **梅丽号在司法岛之后强制烧掉**：这是全篇唯一不可逆的事件，她的日志里会留一条。情感高点比任何数值都值钱

## 7. 收藏：名刀、果实、图鉴

- **名刀**：无上大快刀 12 工 / 大快刀 21 工 / 良快刀 50 工 / 业物。可装备给船长或剑士，带一条「刀的性格」（影响一次判定）
- **恶魔果实**：超人系 / 动物系 / 自然系 / 幻兽种。吃下**不可逆**，给技能但掉「海水」抗性——落水事件会因此变危险。配置可设「只收藏不吃」
- **功能道具**：永久指针、电话虫、海楼石、历史正文（集齐 4 块解锁隐藏章「空白的一百年」）
- **图鉴**：60 项，完成度给全局被动（掉落 / 交涉 / 暴击）

## 8. 成长：等级 + 天赋 + 霸气

- 船长 Lv1–99，经验来自章节与 BOSS，每级 +战力
- 每 5 级 1 点天赋：航海 / 战斗 / 交涉 / 幸运，四条各 5 级封顶
- 新世界解锁**霸气**（见闻 / 武装 / 霸王），是后期唯一的乘法轴，避免线性膨胀

## 9. 自动冒险：她不需要你在场

三种模式，默认第二种：

| 模式 | 谁决定航线 | 她说话 |
|------|-----------|--------|
| 手动 | 你点 | 每次回来都说 |
| **参谋**（默认） | 她按剧情进度自己挑，只在你在线时结算 | 重要的事才说 |
| 全自动 | 完全自己跑，包含 BOSS | 按阈值 |

- **节奏**：30 / 60 / 90 / 180 分钟，默认 90
- **每日上限**：默认 6 次，防止一晚上刷完 119 章
- **离线补偿**：按时间戳补结算，最多 8 次；超出的算「错过」，**不掉任何东西**——不做体力惩罚
- **推送阈值**（关键的成本开关）：
  - 普通航次：静默，只写日志（**0 token**）
  - 船员加入 / 稀有掉落 / 跨章节 / BOSS 结果 / 被俘：推一条 20 字事实，她自己说（约 350 token）
- 按默认设置，一天真正的模型调用 4–6 次，约 2 千 token。**挂机不烧钱，说话才烧钱**

## 10. 面板：从 4 页到 6 页

`航海图`（下一步只有一个按钮）· `年代记`（进度条 + 已过章节的一句话回顾）· `船员` · `船与装备` · `图鉴` · `排行榜`

「下一步」永远只显示一个主按钮，其余收进「自由航海」。决策疲劳比内容不足更容易劝退。

## 11. 工具与提示词预算（这是硬约束）

| 工具 | 作用 |
|------|------|
| `op_state` | 读：篇/章/等级/队伍/船/下一步 |
| `op_act` | 做：sail / boss / auto / recruit / equip / upgrade / repair |
| `op_codex` | 查：名刀 / 果实 / 图鉴 |

常驻环境提示词 ≤150 字，只放一行状态：`第二部·和之国 3/7｜Lv66｜阳光号｜队：索隆/罗宾/甚平｜下一步：鬼岛`。
一次回执给模型的事实 ≤120 字——**它只负责说，不负责算**。

## 12. 配置项（10 项）

`自动冒险` `节奏(分钟)` `每日上限` `叫不叫她` `剧情优先/自由航海` `难度` `船员上限` `果实能不能吃` `允许跳章` `名词表`

## 13. 存档

在现有 `onepiece.json` 上增量：`campaign{part, arc, chapter, flags[]}`、`crew[]`、`ship{}`、`items[]`、`codex{}`、`level/exp`、`talents{}`、`haki{}`、`auto{lastRunAt, runsToday, day}`。
119 章的进度用数组存，整档预计 60–150 KB，仍然单文件。

## 15. 需要你拍板的两件事

**A. 她在故事里是谁？**

- **同行者（推荐）**：她是同期出海的另一条船，草帽团是盟友。剧情节点她「参与」而不「替代」——顶上战争她去救人，和之国她参战。榜上 60 个原角色不用动，船员招的是同期独立海贼（薇薇、罗、甚平、加洛特、大和这类换过船的人 + 原创）。
- **我就是路飞**：把船长名换成路飞，榜上移除路飞，草帽团全员可招募。代入感最强，但她就不再是「你的桌宠」，而是「你在玩路飞」。

**B. 普通航次要她说话吗？**

- 默认**不说**（0 token，只在 BOSS / 稀有掉落 / 船员加入时开口）。
- 如果你更想每天看到她讲两句，可以把「叫不叫她」调成「每次都说」，代价是一天约 8 千 token。

---

**风险**：剧情文本约 1.5 万字（本地，不花 token，但要写）；原作名词有版权，公开上 npm 需切「无风带」皮，剧情也要改成原创岛；挂机容易把她变成数值机器，所以每篇必须留一次「名场面独白」当她的人格锚点。

## 16. v0.4 / v0.5 落地记录（0.5.0）

设计稿里的第 6–8 节按原样做了，但有几处必须现场改，记在这里，免得下次又踩。

**战力改成乘法，难度跟着一起缩放。**
原来是 `10 + 3.2×等级 + 船员 + 船 + 装备`，加法。加了名刀、果实、霸气、六个部件之后，
加法会让后期每一项都变成零头。改成 `等级底子 ×（1 + 各项百分比）`，每项都按比例生效。

随之而来的问题是「难度怎么办」：玩家凭空多了三成加成，原来调好的墙立刻变平地。
解法是让难度也跟着走——`章节难度 = 原难度 × expectedMul(章号)`，
`expectedMul` 只算**白给**的部分（船员按剧情上船、船的档次按剧情换），
名刀 / 果实 / 霸气 / 改装件不算。于是：

- 一个「只推剧情、什么都不买」的人，比值和 0.3.2 完全一样，墙还在；
- 一个把收藏做满的人，多出 20–30% 余量，过门更轻松——这是他花力气换来的。

**门从 ×1.36 抬到 ×1.50。**
因为「一路推主线」的人也会因为「碾压」多拿 25% 经验，等级比预期高一截。
用 `npm run balance` 三种画像对着调：只推主线 146 步 / 27 趟自由航海收尾；
正常玩 125 步 / 6 趟；一路硬推会吃 15 次 BOSS 败走。

**BOSS 三回合用的是同一次掷骰。**
最早的写法是三个回合各掷一次，结果分布是双峰的：要么三胜要么全输，
中间那档几乎抽不到。改成「掷一次，摊到三条线（90 / 96 / 104）」，
赢两回合即过，过门门槛落在 0.96——和 0.3.x 的单掷门槛一致，手感没变，
但「差一点」变成了一个看得见的数字。

**果实是唯一不可逆的东西。**
船员白给、刀可以买、霸气只涨不掉、改装随时能升，只有果实：一辈子一颗，
吃了怕海水。它是这个模式里唯一一个「想清楚再点」的按钮，所以面板上要二次确认。

**没有新加工具。**
船员、船坞、收藏全在面板里点，结算全在本地。模型只在被问起时用 `sea_status`
看一眼（状态行多两三行），所以常驻 token 还是 555。

## 17. v0.6 落地记录（0.6.0）

这一版做的是设计稿第 9–11 节：梅丽号、历史正文、隐藏章，外加派遣与羁绊。
但真正花时间的不是加法，是**三个只有跑起来才会露头的死锁**。记在这里，免得下次重犯。

**死锁一：等级到顶 + 重试加价。**

0.5.0 的门是 ×1.50，玩家靠「决着 +10% 算进整场」这个 bug 拿到了额外余量，所以显得刚好。
0.6 把 bug 修对之后，只推主线、不买不改装的画像在最后一关前面卡了 1500 步：
等级封顶 99，战力 486，门 548，而且每失败一次难度再 +8%（最多 +24%）。
`npm run balance` 里它跑到 1500 步还没出去——这就是死锁，不是「难」。

两条解法缺一不可：
1. **等级上限 99 → 120**：练级永远是路，不能练到头还被墙挡住。
2. **重试加价会松**：`attempts` 隔 3 天（章节天数）归零。剧情上的说法是「对方也会松懈」，
   机制上的作用是「卡住的人有别的选择，而不是越打越绝望」。

顺带发现掷骰种子没算天数：种子是 `seed:章:次数:进度`，加价松掉之后次数回到 1，
同一天重打就永远是同一个结果。加了 `state.day` 进去才有变化。

**死锁二：船的档次从来没升过。**

`state.ship.tier` 只在建号和迁移时写一次，`powerOf` 读它，`expectedMul` 却按「这个位置该有的船」算难度。
于是玩家一直在用 2% 的小帆船加成打按 6% 的巨人战船算的难度，越到后期差得越多。
修法是把档次变成**算出来的**（`shipTierOf(state)`），并且每次结算把它同步回存档，
别让存下来的是一份假数据。顺手把两个剧情节点对齐：梅丽号第 10 章（西罗布村给的），
阳光号第 58 章（司法岛之后，正好接上梅丽号沉掉那件事）。

**死锁三（差一点）：BOSS 回合加成的作用范围。**

「决着 +10%」原本乘在整场三回合上。三条线是 0.90 / 0.96 / 1.04，过门看的是第二条，
所以整场 +10% 等于把门槛从 0.96 降到 0.873——三回合变成走过场，玩家以为自己在打三个回合，
其实只是在看一个被放大的单次判定。改成只乘决着那一回合之后，**这个被动才有意义**：
它不会帮你过门，但会把 2 胜变成 3 胜，而且「差一点」变成了决着那一栏里看得见的数字。

**派遣和羁绊的取舍。**

- 羁绊只做**情境加成**（BOSS 决着、赏金、掉落、回船体、被俘率），一项都不进基础战力。
  理由：进了基础战力就得进 `expectedMul`，而 `expectedMul` 是「白给的部分」，
  羁绊本来就是白给的——两边一起涨，等于没做。情境加成不需要动难度表。
- 派遣按**章**算而不是按分钟，因为时间尺度就是章节；但留了一条天数保底（8 天），
  否则「卡住了只能自由航海」的人派出去的人永远回不来。
- 人被派走的这几章，战力、被动、羁绊一起停。这是派遣唯一的代价，必须真的生效，
  否则它就变成白拿。`activeCrew(state)` 是所有加成函数唯一的入口。

**历史正文为什么挂在 BOSS 身上而不是做成拾取。**

四块石碑就是四个「你打过这里」的凭证，做成随机掉落只会让人反复刷。
现在打完必得，图鉴里单独一栏，凑齐 4/4 解锁隐藏章——这条线是给「已经通关还想再打一场」的人准备的，
所以它不进主线进度，输了不掉任何东西。

**隐藏章的难度写法。**

不能写死数字，否则以后调剧情难度它就不对了。做法是反推：
`目标 = 结局那一章 × 1.18`，再除以 `expectedMul(120)` 得到 `chapter.power`，
让 `chapterPowerOf` 算回去正好是目标值。这样无论难度表怎么改，它永远比结局硬 18%。

## 18. v0.7 界面重做与收藏扩容（0.7.0）

这一版没有新机制，回答的是三个界面上的抱怨：
「横幅太简陋」「战力像 Excel」「收藏的名刀太少」。

**为什么是两栏，而不是把卡片做小。**
面板在宿主里大约是 800px 宽。单栏时所有东西排队往下堆，一屏只能看见三张卡，
而且「现在能做的」被压在剧情下面——它本来是最该被看见的东西。
两栏不是把内容挤窄，是**分工**：左边是「发生了什么」，右边是「她现在怎么样」。
780px 以下回落成一栏；820px 左右右栏会自动把五个槽位缩到 40px、把六个部件排成两行，
这些阈值都是照着宿主截图量的。

**为什么把进度条换成「对决绳」。**
两根并排的横条，不管怎么调颜色，看起来都是加载条；而且两根条各自占满宽度，
会有「我 87% 他 100%」的错觉——明明只差 16 点，看起来像差一大截。
换成一条绳子按两边的力气分：中间那颗星就是交手点，它往左移就是你被压着，
上面直接写「差 16」。**一眼看到的是比例，不是进度**。

**为什么战力要变成槽位。**
原来五行「船员 +0 / 船 +0 / 名刀 +0」在开局全是 0，像一张没填的表。
槽位的好处是「空」本身也是信息：暗着的圆环告诉你这里还能长东西，亮起来才是 +30%。
这和游戏里的装备栏是同一套心理模型，不需要解释。

**33 把刀差点把数值毁了。**
第一版给每把刀按「无上 / 大快刀 / 良快刀」定了 0.042~0.058 的战力，
结果 `npm run balance` 三种画像全部 30/0 通 BOSS，墙没了。
原因不是刀太强，是**刀太密**：一个篇章白送一把，玩家每三章就换一次刀架，
最强三把始终是「最近三把」，等于一条平滑上升的免费曲线。
把整条曲线压平之后（终局最强三把 +13.7%，和 0.6 的 +13.5% 持平），
只推主线的画像回到 17 趟自由航海（0.6 是 19 趟），墙又回来了。
**教训：收藏的数量变了，单件的强度必须跟着除。**

一个篇章一把还有两个好处：掉落逻辑不用抽卡（`bladesForArc` 一定只有一把，
以后加第二把也不会漏），以及「没到手也知道去哪找」——卡片上直接写出处。

**果实只加种类，不加规则。**
新增 12 颗果实全部复用原来六条真规则（减伤 / 贝利 / 决着 / 回船体 / 疲劳 / 悬赏）。
不为了「看起来多」去写七条半成品规则：面板上写了「+30% 贝利」，
代码里就必须真的乘在 `berryMul` 上，否则收藏就变成读文字。
契约测试里加了一条断言，新果实的 `effect` 必须在这六个里。

**悬赏令为什么不画脸。**
画脸这件事已经被否过两次：第一版手绘五官「有点恶心」，第二版全黑剪影又像一块墨。
现在的做法是**网点 + 剪影**——只画帽子、肩膀和领口，脸留空，
靠 22° 的网点、红日和纸纹撑住画面。它像一张拓印，不像一张画坏的人像。
领口那个白色的 V 是必须的：没有它，头和肩膀会连成一团黑。

**token 还是没动。**
插画、槽位、热区、网点全是浏览器里画的 SVG/CSS；宿主和世界之间传的仍然只有
`ctx.invoke('state')` 这一份本地 JSON。界面变复杂不会进模型上下文。

## 19. v0.8 复古航海视觉（0.8.0）

这一版只动皮，不动骨：没有新玩法、没有新工具、没有新存档字段。
但有三处不是「换个颜色」就能解决的，记下来。

**一、白底卡片是割裂感的根源，不是配色问题。**

0.7 的面板其实已经有插画、有槽位，但卡片是「白底 + 浅灰阴影 + 16px 圆角」——
这是网页后台的形状，放在一张画旁边就永远是「图 + 卡」两件东西。
真正把割裂感去掉的是三件事同时做：

1. 卡片和页面**用同一种纸**（同一个 `--paper` 变量、同一层 grain），只是卡片的纸上多一层内描边当厚度；
2. 阴影从「外面一圈灰」换成「里面一圈浅、外面一道褐」——纸张是叠起来的，不是浮起来的；
3. 圆角从统一 16px 改成不对称（3/9/4/8），边角不再是一个模子。

只改其中一条都会留着那股「组件库」味。截图里 0.8 的卡片没有任何投影，反而更像纸。

**二、撕边必须用 px 算，不能用百分比。**

`clip-path: polygon()` 的百分比是相对**元素自身宽高**的。
横幅高 172px、航线卡图带高 96px，同一个百分比振幅在两者上会是 1.8 倍差；
宿主面板宽度还会变，波形跟着拉伸，看起来就像锯齿而不是撕口。
所以 `tearEdge(steps, amp, phase)` 用 `calc(100% - Npx)` 生成固定像素振幅，
再按段数取 `|sin(i·phase)|` 做不规则——同一个函数给横幅（22 段 / 11px）和航线带（13 段 / 8px）。

撕边还有两个副作用要一起处理：
- 横幅被裁之后，船会掉出边缘 → 船从 `bottom:4px` 抬到 `11px`；
- 撕口会露出后面的纸，所以横幅外层要 `filter: drop-shadow()` 而不是 `box-shadow`（后者会被裁掉）。

**三、铅字和印章不能靠字体，得靠滤镜。**

「旧报纸那种斑驳的粗衬线」在系统字体里找不到；就算找到，也不可控。
做法是把文字画进内联 SVG，套 `feTurbulence + feDisplacementMap`（scale 2.6）——
位移量正好是一两个像素，边缘就被啃出毛刺，放大看是烂铅字，缩小看是「旧」。
再垫一层浅色文字、往下偏 1.6px，就是凸版印刷的高光。

印章同理：位移（scale 3.8）+ 0.32 模糊 = 墨晕，然后用三道**纸色**的缺口矩形
把边框啃掉几块 = 残缺。这比用 mask 加噪点稳，也不依赖外部图片。
印章放在照片右上角、顺时针 15°——压在 WANTED 上会挡住字，压在照片角上才像盖上去的。

**其余都是常规操作，一句话带过：**

- 铜徽章 = 径向渐变 + 2px 褐边 + `inset` 高光 + 一圈虚线内环；亮起来只是换成金币色，形状不动；
- 黄铜齿轮 = 同一个配方 + `ico('gear')` + hover `scale(1.22)`；
- 木牌 = 米黄渐变 + 1.5px 褐边 + 底部 `0 2px 0 褐` 的实心边（这就是「凸起」的全部秘密）；
- 木纹 = `pattern` 平铺两三条正弦曲线，40% 不透明度，只铺在船体那条路径上；
- 羁绊红绳 = `repeating-linear-gradient(115deg)` 的红白条纹 + 两端各一颗圆结。

**代价：零。**

没有一个外部字体、一张位图。grain 是 `feTurbulence` 生成的 data URI（约 1.2KB），
其余全是 CSS 渐变和内联 SVG。`package.json` 的体积没变，token 也没变——
面板画什么、画多细，都不进模型上下文。
